# ReCircle brand assets

This directory is reserved for the official ReCircle artwork supplied by the
project team. Do not replace these files with generated or generic artwork.

## Logos

- `logos/recircle_logo_dark.jpg` — official horizontal logo for dark
  backgrounds.
- `logos/recircle_logo_light.jpg` — official horizontal logo for light
  backgrounds.

Use the version with sufficient contrast for the surface. Keep the supplied
design and colors unchanged.

## Application icon

- `icons/recircle_app_icon.jpg` — official square source image for launcher and
  branded splash use. Android launcher density/adaptive-icon outputs should be
  derived from this source without changing the logo design.

Flutter and Android native splash resources reference these supplied JPEGs.
Android density and adaptive launcher outputs are derived from the app icon.
The `banners/` folder is reserved; the Home hero is drawn with Flutter widgets,
so no unapproved or stock banner image is included.
